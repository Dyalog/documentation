

# <span>FILE NAME QUOTA USED UP</span> `32`

This report is given when the user attempts to execute a file system command that would result in the User's File Name Quota (see [Component Files](../introduction/component-files.md)) being exceeded.

This can occur with `⎕FCREATE`, `⎕FTIE`, `⎕FSTIE` or `⎕FRENAME` .
