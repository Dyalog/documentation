# <span>Name List</span> `⎕NL`

## Monadic `⎕NL` means

[List Object Names](nl-monadic.md)
```apl
      plus←+ ⋄ power←* ⋄ minus←-
      ⎕NL 3
minus
plus 
power
```

## Dyadic `⎕NL` means

[List Object Names with Filter](nl-dyadic.md)
```apl
      plus←+ ⋄ power←* ⋄ minus←-
      'p'⎕NL 3
plus 
power
```
