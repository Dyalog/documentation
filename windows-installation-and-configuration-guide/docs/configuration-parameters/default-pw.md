# Default_PW

This parameter specifies the value of `⎕PW` in a clear workspace. `⎕PW` is a property of the Session, and the value of **Default_PW** is overridden when a Session file is loaded.

Valid values are those of `⎕PW`: an integer from `42` to `32767`.

The default is `76` on Microsoft Windows and `79` on UNIX and macOS.
