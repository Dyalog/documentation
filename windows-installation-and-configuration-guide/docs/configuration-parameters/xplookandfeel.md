# XPLookAndFeel

!!! Info "Information"
    Dyalog reads this configuration parameter before it loads any configuration file, so setting it in an application or user configuration file has no effect. Set it on the command line, as an environment variable, or in the Registry.

This Boolean parameter specifies whether or not *Native Look and Feel* is used. This affects the appearance of user-interface controls such as Buttons. The default is 1.
