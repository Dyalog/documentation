# XPLookAndFeel

!!! Info "Information"
    Dyalog reads this configuration parameter before it loads any configuration file, so setting it in an application or user configuration file has no effect. Set it on the command line, as an environment variable, or in the Registry.

This Boolean parameter specifies whether *Native Look and Feel* is used. This affects the appearance of user-interface controls such as Buttons.

The default is `1`.

!!! Info "Information"
    The functionality enabled by XPLookAndFeel was disabled by default in Dyalog v19.0; the ability to re-enable it will no longer be available once this configuration parameter has been removed. XPLookAndFeel is scheduled for removal in Dyalog v22.0.
