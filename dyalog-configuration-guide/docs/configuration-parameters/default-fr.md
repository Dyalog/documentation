# Default_FR

The value of [`⎕FR`](../../language-reference-guide/system-functions/fr.md) (floating-point representation) in a clear workspace.

Valid values are those of `⎕FR`: `645` or `1287`. Any other value is ignored.

Default is `645`.

See also the [Session tab](../../windows-installation-and-configuration-guide/configuring-the-ide/configuration-dialog.md#session-tab) of the Windows Configuration Dialog.
