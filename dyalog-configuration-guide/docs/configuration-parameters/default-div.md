# Default_DIV

The value of [`⎕DIV`](../../language-reference-guide/system-functions/div.md) in a clear workspace.

Valid values are those of `⎕DIV`: `0` or `1`.

Default is `0`.

See also the [Session tab](../../windows-installation-and-configuration-guide/configuring-the-ide/configuration-dialog.md#session-tab) of the Windows Configuration Dialog.
