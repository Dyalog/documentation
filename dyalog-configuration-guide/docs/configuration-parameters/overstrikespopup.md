# OverstrikesPopup

!!! Info "Information"
    This configuration parameter is only relevant when using the Unicode edition of Dyalog.

Whether the Overstrikes popup is enabled.

Valid values are:

- `0` : the Overstrikes popup is disabled
- `1` : the Overstrikes popup is enabled
