# ResolveOverstrikes

!!! Info "Information"
    This configuration parameter is only relevant when using the Unicode edition of Dyalog.

Whether an APL composite symbol can be entered using overstrikes.

Valid values are:

- `0` : overstrikes are disabled
- `1` : overstrikes are enabled
