# ValueTips/Enabled

Whether Value Tips are enabled. When enabled, Dyalog displays the value of a variable, or the code of a function, when the mouse hovers over its name.

Valid values are:

- `0` : Value Tips are disabled
- `1` : Value Tips are enabled
