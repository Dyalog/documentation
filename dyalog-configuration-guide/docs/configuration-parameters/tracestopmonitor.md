# TraceStopMonitor

Which of the `⎕TRACE`, `⎕STOP`, and `⎕MONITOR` columns are displayed in Trace and Edit windows. The value is the sum of the codes for the chosen columns.

The value is the sum of the following:

- `1` : the `⎕TRACE` column
- `2` : the `⎕STOP` column
- `4` : the `⎕MONITOR` column
