# PFKey_Size

The size of the buffer used to store programmable function key definitions (see [Program Function Key (`⎕PFKEY`)](../../../language-reference-guide/system-functions/pfkey)). If the buffer is too small, adding a new definition signals a `LIMIT ERROR`. See [Specifying Size-related Parameters](configuration-parameters.md) for how to give a valid size.
