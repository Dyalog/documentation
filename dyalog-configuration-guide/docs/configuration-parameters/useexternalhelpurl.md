# UseExternalHelpURL

This parameter specifies whether or not Dyalog attempts to use the Microsoft Document Explorer and online help to display help for external objects, such as .Net Types. See [ ExternalHelpURL](externalhelpurl.md).

See also [Use Microsoft's documentation centre for non-Dyalog topics](../../../windows-installation-and-configuration-guide/configuring-the-ide/configuration-dialog/configuration-dialog-help-dmx-tab.md).
