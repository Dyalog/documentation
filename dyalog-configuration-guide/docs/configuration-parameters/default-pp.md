# Default_PP

The value of [`⎕PP`](../../language-reference-guide/system-functions/pp.md) (print precision) in a clear workspace.

Valid values are those of `⎕PP`: an integer from `1` to `34`.

Default is `10`.

See also the [Session tab](../../windows-installation-and-configuration-guide/configuring-the-ide/configuration-dialog.md#session-tab) of the Windows Configuration Dialog.
