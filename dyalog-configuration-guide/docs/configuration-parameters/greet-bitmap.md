# Greet_Bitmap

The filename of a bitmap displayed during initialisation of the Dyalog application, typically to show a product logo from a run-time application. The bitmap remains until an error occurs or it is removed using the [GreetBitmap](../../../object-reference/methodorevents/greetbitmap) method of the Root object. For example, `Greet_Bitmap=c:\myapp\logo.bmp`.

Valid values are a file path.
