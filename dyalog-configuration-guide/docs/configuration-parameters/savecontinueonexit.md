# SaveContinueOnExit

Whether the current workspace is saved as `CONTINUE.DWS` before Dyalog terminates.

Valid values are:

- `0` : the workspace is not saved on exit
- `1` : the workspace is saved as `CONTINUE.DWS` on exit
